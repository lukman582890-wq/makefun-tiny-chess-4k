Deterministic <=4 KB Python 3.13 chess engine (PeSTO tapered MG/EG PST, bishop pair, endgame king mop-up, PVS/Negamax, TT, NMP, RFP, LMR, Futility, QSearch + MVV-LVA, killers, history, repetition/50-move draw).

## Run it

```sh
python3 -P -s main.py
```
